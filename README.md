v0.7.50 COST / PRICE AUDIT — PAPER и отдельная симуляция

Новый блок дашборда разделяет изменение цены, комиссии и создание счетов.
Для каждого PAPER-выхода показаны ближайшая попытка, продажа до тика
и продажа после тика, разница времени результата/снимка, slot и обе цены.
Поздняя проверка — только диагностика. Дополнительных RPC нет.
Основной PAPER, SIGNAL_EXIT_V1, NET10/RESERVE50/DELTA10 и допуск 0 мс сохранены.

Запуск в новой папке. Старую папку и результаты сохраните:
1. 01_INSTALL.bat
2. 02_SETTINGS.bat — перенесите API-настройки; пороги не меняйте.
3. 04_CHECK.bat при остановленном боте.
4. После PASS — 03_START.bat (повторная проверка часов).
Дашборд: http://127.0.0.1:8185
5. После теста штатно остановите бот, выполните 05_RESULTS.bat.
Пришлите полный архив. Новый файл: cost_price_audit.json.
Старые базы не переносите. Часы во время теста не меняйте.

Модельный объём токенов, локальная симуляция без отправки транзакций.
Сравнение расходов не устраняет различие источников цен и влияние объёма.
Подробности: docs/v50_cost_price_policy.txt
